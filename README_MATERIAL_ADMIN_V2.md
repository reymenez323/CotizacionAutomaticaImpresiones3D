# Materiales y colores - versión mejorada

Cambios:
- Tarjetas con colores visuales según estado:
  - disponible,
  - agotado,
  - oculto.
- Botón para eliminar materiales del catálogo.
- Botón para eliminar colores.
- Modificación mediante popup/modal.
- Los colores se agregan como chips:
  - escribes el color,
  - presionas Enter, Espacio, coma o el botón Añadir.
- Al modificar un material, los colores mostrados en el modal reemplazan la lista anterior.
